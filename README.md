# AI 英语智能语音通话伴学伙伴 (AI Voice Tutor)

专为小学生与初中生打造的 **ChatGPT 风格全双工自主语音通话对练系统**。
支持免提自然对话、自动静音断句感应（VAD）、大模型即插即用、课件动态热插拔。

---

## 🚀 快速启动

进入本目录，直接双击运行：
👉 **`启动AI语音通话.bat`**

系统会自动启动本地轻量服务，并弹出浏览器窗口访问 `http://localhost:3000`。

---

## 🌟 核心特性

1. **ChatGPT 风格高级语音通话**：
   - 屏幕中央为灵动呼吸声波球，随说话状态呼吸变色；
   - **完全免提（零按键）**：开麦后孩子直接说英语，AI 自动感应到孩子说完后即时思考并用自然语音开口接话；
   - **自主连续循环**：AI 说完自动继续倾听，无需重复点击。

2. **🧠 大脑模型随时切换 (Model Provider Pluggable)**：
   - 点击右上角 **⚙️ 设置**；
   - 内置一键预设：
     - **DeepSeek (官方)**
     - **阿里通义千问 (DashScope)**
     - **SiliconFlow (硅基流动)**
     - **OpenAI (GPT-4o)**
     - **本地离线 Ollama (零成本免联网)**
     - **自定义接口**
   - 填入对应 API Key 即可实时切换大脑！

3. **📚 课件随时热插拔 (Courseware Hot-plug)**：
   - 根目录下有 `courseware/` 文件夹；
   - 只要丢入一个新的 `.json` 文件，界面顶部下拉菜单会自动多出一个课件选项；
   - 已内置课件：
     - `pep-3a-u1.json` (小学三年级上册 Unit 1: Making friends)
     - `pep-3a-u2.json` (小学三年级上册 Unit 2: Different families)
     - `pep-7a-u1.json` (初中七年级上册 Unit 1: You and Me)
     - `free-chat.json` (自由口语畅聊)

4. **🎓 专属教学调优**：
   - 语速可调（推荐小学生 0.85x）；
   - 自动隐性重铸（Recast）：孩子即使语法说错，AI 不生硬打断，用正确句子自然顺承，保护孩子表达信心；
   - 实时双语字幕辅助显示。
